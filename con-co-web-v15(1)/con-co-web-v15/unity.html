Không gian Unity

Khu vực nhúng trò chơi Unity chạy trong trình duyệt. Phần này đang chờ bạn hoàn tất bản build WebGL trong Unity.

Cách kết nối sau này

  1. Trong Unity, build dự án bằng nền tảng WebGL.
  2. Tạo thư mục unity-build ngay cạnh file index.html của website.
  3. Chép toàn bộ file build WebGL vào thư mục đó, bao gồm file index.html.
  4. Tải lại trang này để trò chơi hiển thị trong khung bên dưới.

Không tải riêng file HTML; cần giữ đầy đủ các file JavaScript, dữ liệu và WebAssembly do Unity tạo ra.

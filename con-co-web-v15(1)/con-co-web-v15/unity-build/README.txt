UNITY WEBGL BUILD FOLDER

This folder is intentionally a placeholder.

After building your project for WebGL in Unity:
1. Copy ALL files and folders generated by Unity into this folder.
2. The final path must be: unity-build/index.html
3. Keep Unity's Build, TemplateData and other generated files/folders together.
4. Run the website through a local web server or a web host; avoid opening the player with file://.

Do not copy only index.html. The JavaScript, WebAssembly, data and supporting files are required.

Đây là tab riêng để bạn tự phát triển và tích hợp bản Unity. Website đã chuẩn bị sẵn vị trí nhúng; bạn chỉ cần chép bản build WebGL vào đúng thư mục.

UNITY WEBGL PLAYERThư mục: unity-build/

Chưa có bản Unity được thêm vào

Khi bạn build Unity sang WebGL, hãy chép toàn bộ nội dung thư mục build vào thư mục unity-build/ nằm cạnh file unity.html.

Trong đó cần có file index.html cùng các thư mục/tệp build do Unity xuất ra. Không chỉ chép riêng file HTML.

Cách đưa bản Unity của bạn vào đây

  1. Trong Unity, chọn nền tảng WebGL và thực hiện Build.
  2. Mở thư mục kết quả Unity đã xuất.
  3. Chép tất cả tệp và thư mục trong kết quả build vào con-co-web-v15/unity-build/.
  4. Đảm bảo đường dẫn cuối cùng là unity-build/index.html.
  5. Mở website qua máy chủ web để chạy thử. Không nên mở trực tiếp bằng file://.

Trang này chỉ là khung nhúng. Chưa có trò chơi Unity đi kèm; nội dung 3D là phần bạn sẽ tự thêm.

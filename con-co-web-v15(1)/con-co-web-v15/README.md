LỊCH SỬ BẢO VỆ ĐẢO CỒN CỎ

Mở index.html hoặc home.html để xem trang chủ.

Chạy trên máy tính:
1. Cài Python nếu máy chưa có.
2. Mở thư mục này trong Terminal hoặc Command Prompt.
3. Chạy: python server.py
4. Mở http://127.0.0.1:8000 trên trình duyệt.

Website dùng HTML, CSS và JavaScript. Không cần Python khi đưa lên dịch vụ hosting cho web tĩnh. Python chỉ được dùng ở đây để chạy trang web trên máy tính.

Các trang chính:
- home.html: trang chủ
- journey.html: dòng thời gian lịch sử
- document.html: tài liệu và video
- exam.html: 30 câu trắc nghiệm
- game.html: thử thách tư liệu lịch sử
- research.html: nghiên cứu
- sources.html: nguồn tham khảo
- progress.html: tiến độ lưu trên trình duyệt

Tiến độ và ghi chú được lưu trong trình duyệt hiện tại, không phải cơ sở dữ liệu dùng chung.
